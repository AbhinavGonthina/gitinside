# axios-defaults

Tests: `defaults.baseURL` assigned after axios is imported or an instance is created (M5A.3d). `@defaults/web`'s `services/fetcher.ts` sets `axios.defaults.baseURL = \`${API_URL}/api/v1\`` at its top level (`API_URL` an env var with a loopback fallback), so `getUser` reaches `GET /api/v1/users/:id`. `services/admin.ts` creates `admin = axios.create({ timeout: 5000 })` and then assigns `admin.defaults.baseURL = "/api/admin"`, so `listUsers` and `ban` reach `GET /api/admin/users` and `POST /api/admin/users/:id/ban`. All three are `heuristic` because the URLs are matched across services. `services/session.ts` assigns its instance's base inside `configure(base)`, which may run any number of times with any value, so `refresh` stays unresolved `DYNAMIC_URL` (the baseURL can't be read), though `@defaults/api` has a `POST /api/v1/session/refresh`.
