# typed-sdk-base

Tests: TypeScript SDK clients whose declarations name a type (M9.7d, review findings G1, G2, G5). `LocalModel`'s `private openai: OpenAI` is set in its constructor to a client built with `baseURL: "http://localhost:11434/v1"`, so `chat.completions.create` reaches the repo's own `POST /v1/chat/completions` (`heuristic`, a loopback base) rather than OpenAI's host. `const groq: OpenAI = new OpenAI({ baseURL: "https://api.groq.com/openai/v1" })` is an external call to `api.groq.com`. `Embedder`'s client is known only by its type (a parameter property), so its request is unresolved (`DYNAMIC_URL`), and so is `routedChat`'s: its client is built with OpenRouter's base on one branch and OpenAI's default on the other. `lastFastChat` reads a mocked method's `.mock.calls`, which isn't a request. `upstream.ts`'s `relay` (M9.7e, review finding G3) calls through `new OpenAI({ baseURL: process.env.UPSTREAM_BASE_URL })`, and `.env.example` sets that var to `https://api.openai.com/v1`, so it's an external call to `api.openai.com` (`heuristic`, an example's value), not the repo's own `POST /v1/chat/completions` that the example's `/v1` path would reach (ADR-0265).
