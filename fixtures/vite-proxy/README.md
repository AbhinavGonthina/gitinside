# vite-proxy

Tests: dev proxies between a SPA and its API (ADR-0204). `@vite-proxy/client`'s `vite.config.ts` proxies `/api` to `http://localhost:5000` with `rewrite: (path) => path.replace(/^\/api/, "")`, `/auth` to the same server unchanged, and `/weather` to `https://api.weather.example.com`. So `fetch("/api/users")` is a `heuristic` edge to `GET /users` in `@vite-proxy/server`, not to its `GET /api/users` decoy; `/api/users/${id}` reaches `GET /users/:id`; `/auth/login` reaches `POST /auth/login`; `/weather/${city}` is an `external_call` to `api.weather.example.com` at `heuristic`; and `/api/orders`, sent as `/orders`, matches no route and is `unresolved` with a detail naming the proxied path, rather than guessing the unrewritten one. `@vite-proxy/admin` is a Create React App (`react-scripts`) whose `package.json` `"proxy"` sends `fetch("/stats")` on unchanged to `GET /stats`. The config is read as syntax, never loaded or run.
