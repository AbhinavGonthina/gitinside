# config-wrapper

Tests: a wrapper whose parameter is the whole axios config (M5A.3c). `@config/web`'s `services/fetcher.ts` exports `httpRequest = (req: AxiosRequestConfig) => new Promise(async (resolve, reject) => { … await axios(req) … })`: the request sits in a callback inside the wrapper, and its URL lives in the config. `services/api.ts` calls `httpRequest({ method: "POST", url: "/authenticate", data })`, `httpRequest({ method: "GET", url: \`/post/${postID}\` })`, and `httpRequest(LOGOUT)` with a const object, so each call is its own request with the caller's `url` and `method`: edges from `login`, `getPost`, and `logout` to `POST /authenticate`, `GET /post/:id`, and `DELETE /logout` in `@config/api`, `heuristic` because a root-relative URL is matched across services. `forward(config)` passes its own parameter on, so its request is unresolved `WRAPPER_DEPTH`.
