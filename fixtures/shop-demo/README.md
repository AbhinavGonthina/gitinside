# shop-demo

Tests: one request path end to end, across two services, and the graph the viewer prototype (M4a.7) is drawn from. `@shop/web` (Next.js) renders `/checkout`, whose `Checkout` component calls `placeOrder`, which fetches `${NEXT_PUBLIC_API_URL}/api/orders` (`heuristic` to `POST /api/orders` in `@shop/api`). The Express route mounted at `/api/orders` is handled by `createOrder`, which writes the Prisma `Order` model (stored in the compose `db` service, linked by host through `.env.example`) and calls `chargeOrder`, a Stripe SDK call ⇒ `external:ext/api.stripe.com`. `/orders` reads through `GET /api/orders` the same way. The home page's `${CMS_URL}/posts` isn't named like an API base, so it is an `unresolved` node instead of a guess. No value from the env file reaches the graph.
