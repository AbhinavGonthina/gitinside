# local-helpers

Tests (M5C.10d, ADR-0032's amendment): a path-taking helper declared inside another function is a wrapper for the calls in its scope. `notesPanel` declares `call(path, init)`, a `const` arrow fetching `${API}${path}`, and calls it from the functions it returns, so each call is a request with its own method (`GET /api/notes`, `POST /api/notes`, `DELETE /api/notes/:noteId`), and nothing is left at `call`'s own `fetch`. `pin(id)` passes its parameter on only in a later segment (`/notes/${id}/pin`), so it fixes the route and isn't a wrapper over `call`: its call of `call` is the `PUT` request. The test declares `get(path)` as a nested function and `send(path, method)` as a `const` arrow on a literal origin, inside a `node:test` callback, and calls each once (`GET /api/status`, `POST /api/notes`, `heuristic` on `localhost`).
