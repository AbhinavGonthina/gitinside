# nested-config

Tests: nested `tsconfig.json`/`jsconfig.json` files (M5C.7g, ADR-0212). One package at the root with no config of its own. `web/` has no `package.json` but has a `jsconfig.json` whose `paths` map `@/*` to `./src/*`, so `notesApi.js`'s `import client from "@/lib/client"` reaches the axios instance and its three calls match `GET /api/notes`, `POST /api/notes`, and `DELETE /api/notes/:id` under the instance's `baseURL: "/api"`. `admin/tsconfig.json` gets its `paths` (`#http`) through `extends` from `config/paths.json`, whose `baseUrl` is relative to that file, so `weekly.ts` reaches the same client and `GET /api/reports/weekly`. `scripts/seed.js` uses the `@/` alias outside `web/`, where no config defines it, so its import stays `unresolved` (`UNKNOWN_SYMBOL`) and its request isn't seen.
