# static-member-base

Tests: URL bases held in static members, `#private` methods, and an object literal's own property (anything-llm's embedded lemond engine, `FoundryCatalog`, Gmail's plugin, and `CommunityHub`, M9.1a7b). `server`'s `Engine` has a static getter `baseUrl` returning `http://127.0.0.1:${port()}`, so `${this.baseUrl}/api/v1/health` in its static `isRunning()` reaches `engine`'s `GET /api/v1/health`, and `EngineLLM.apiBasePath()` (a static method returning `${Engine.baseUrl}/api/v1`) makes `load()`'s request reach `POST /api/v1/load` (`heuristic`: a loopback host with a port only known at runtime, and a member read). `Catalog.CATALOG_URL` (a static field), `Mailer`'s `#getBaseUrl()` (a private method that logs, then returns a template), and `Hub.apiBase` read through `this` in `Hub.explore` are external calls to their hosts (`heuristic`).
