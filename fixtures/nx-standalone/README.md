# nx-standalone

Tests: an Nx standalone app (M6.11j, M6 review S1), shaped like `gothinkster/node-express-realworld-example-app`: `nx.json`, a root `project.json` (`name: "api"`, `sourceRoot: "src"`) with the Express app in `src/`, and an `e2e/project.json` beside it. The `e2e/` project makes the repo an Nx workspace, and the root is still a service because it holds source of its own (ADR-0021 amendment), keyed and labeled by its root `project.json` name (`api`), not the package.json's Nx placeholder (`@api/source`), which stays its importable name. Its `src/` routes, the route's call into `tag.service.ts`, and the root `jest.config.ts` are the root's; the e2e test's request links to `GET /api/tags` (`heuristic`: a literal loopback URL can't say which service listens on port 3000). No file gets `FILES_OUTSIDE_SERVICE`.
